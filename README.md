# WoWhisper

An Add-on for World of Warcraft (Retail), World of Warcraft Classic Era (1.15.9 and other Classic Original clients such as Hardcore), and World of Warcraft Classic Anniversary / Burning Crusade Classic that allows you to select custom colors for your outbound messages in the following channels to improve readability and the overall in-game chat experience:

- /whisper
- /party (/p)
- /guild (/g) & /officer (/o)
- BNet chat
- Public (/1, /2, /3, /battleground (/bg), /say (/s), /instance)

## Features

- **Colored Messages**: Customize the color of your sent messages in various channels (defaults to WoW gold)
- **In-Game Color Picker**: Easy-to-use minimap button and settings UI with visual color wheel
- **Draggable Icon**: Move the minimap button to your preferred positions
- **Persistent Settings**: Your color choices and UI position are saved across sessions
- **Lightweight**: Minimal performance impact using efficient chat filters

## Installation

Via CurseForge:
1. Search WoWhisper and click install

## Customizing Colors

WoWhisper includes an easy-to-use in-game color picker:

1. **Click the WoWhisper minimap button**
   - Or type `/wowhisper` or `/ww` in chat
2. The settings window will open with color selection options.
3. **Click any colored square** to open the color picker wheel
4. **Select your desired color** and click Accept
5. Click **Reset to Defaults** to restore all colors to WoW Gold

### Tips

- The minimap button is **draggable** - hold and drag it around the minimap edge
- Press **ESC** to quickly close the settings window
- All your color choices and UI positions are automatically saved

## Default Colors

All channels default to **WoW Gold** (#FFD700) for a classic, elegant look that's easy to read.
